Step 1: connect your own free database

Your posts, pictures, contacts and banner are stored in your own free Supabase database, so nothing is shared and nothing gets locked. You do this once (about 5 minutes).
1. Go to supabase.com, sign up (free) and press New project. Choose any name and a password you will remember.
2. When the project is ready, open SQL Editor → New query. Press the button below to copy the setup SQL, paste it there and press Run. It must say "Success".
3. Open Project Settings → API. Copy the Project URL, the anon (publishable) key and the service_role (secret) key into the boxes below.
The secret key is kept on our server and used only to post for you at the time you chose. It is never shown in the browser.

How do I get the ID and access key?
1. Go to developers.facebook.com and make an app (type Business).
2. Open Tools → Graph API Explorer, choose your app, and press "Get Page Access Token". Allow pages_manage_posts, pages_read_engagement, instagram_basic and instagram_content_publish.
3. In the Explorer, ask me/accounts: it shows each Page's id and access_token. That is your Facebook Page ID and key.
4. For Instagram, ask {Page ID}?fields=instagram_business_account. That number is your Instagram account ID. Use the same Page key.
5. Your Instagram must be a Professional (business/creator) account linked to the Facebook Page.
WhatsApp: how to set it up
This sends your picture or video as a WhatsApp message to people who agreed to receive it. It is not WhatsApp Status (WhatsApp does not allow that). Meta charges per message.
1. In your Meta app add the product WhatsApp and set up a WhatsApp Business number.
2. In WhatsApp Manager → Message templates create a template of category Marketing with an Image or Video header and a body of exactly one variable: {{1}}. Wait until Meta approves it.
3. Copy the Phone Number ID (WhatsApp → API Setup) and make a permanent key (System User) with whatsapp_business_messaging and whatsapp_business_management.
4. Paste them above with the template name and its language, press Save, then add your contacts. Only add people who agreed.
